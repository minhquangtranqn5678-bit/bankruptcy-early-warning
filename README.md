# Hệ thống cảnh báo sớm doanh nghiệp có nguy cơ phá sản
Tiểu luận môn Khoa học dữ liệu và phân tích kinh doanh (261MIE400202).

Cách chạy:
1. pip install -r requirements.txt
2. python bankruptcy_ews.py
Kết quả (bảng, hình) được lưu trong thư mục results/.

Dữ liệu: Company Bankruptcy Prediction (Kaggle) – https://www.kaggle.com/datasets/fedesoriano/company-bankruptcy-prediction
